# 钳工中级刷题系统

一个部署在 GitHub Pages 上的纯静态刷题网站，无需服务器、无需数据库、完全免费。

## 功能

- **学号登录**：学生输入学号即可登录（账号由教师管理）
- **模拟考试**：每次随机出 100 道单选 + 100 道判断，每题 0.5 分，满分 100 分
- **防重复出题**：与每位学生近 5 次考试的重复率控制在 10% 以内（实际约 5%）
- **成绩与答案**：交卷后立即显示成绩，并附全部题目的答案回顾（答错标红、正确答案标绿）
- **错题本**：自动记录错题并累计错误次数，可反复刷错题（刷题时答错会继续累计次数）
- **高频 / 低频错题库**：错误超过 3 次自动进入高频错题库，3 次及以下为低频
- **手动删除错题**：学生可随时将已掌握的题从错题本删除
- **教师管理**：密码登录，可添加 / 批量添加 / 删除学生账号，可修改教师密码
- **数据备份**：学生可导出 / 导入自己的成绩和错题数据（换电脑时使用）

## 题库

来源：`钳工中级总题库.xls`，清洗去重后共 **1299 题**（单选 875 + 判断 424），全部含答案。

## 部署到 GitHub Pages（5 分钟）

1. 注册 / 登录 [GitHub](https://github.com)
2. 点击右上角 **+** → **New repository**，名称随意（如 `qianzhong-quiz`），选 **Public**，创建
3. 在仓库页面点 **uploading an existing file**，把本文件夹的 **3 个文件**全部上传：
   - `index.html`
   - `data/questions.js`
   - `data/accounts.js`
   （注意保持 `data/` 文件夹结构）
4. 点 **Commit changes** 完成上传
5. 进入仓库 **Settings → Pages**，在 **Branch** 下选择 `main` 分支、`/(root)` 目录，点 **Save**
6. 等待 1~2 分钟，访问 `https://你的用户名.github.io/qianzhong-quiz/` 即可使用

把网址发给学生，学生用学号登录就能刷题。手机、电脑浏览器均可使用。

## 教师使用

- **入口**：网站首页底部"教师管理入口"
- **默认密码**：`teacher123` —— **首次部署后请立即在管理面板修改**，修改后按提示导出文件
- **添加学生**：单个添加，或批量粘贴（每行：`学号 姓名`）
- **重要**：在网页上增删账号后，必须点 **"导出账号文件（accounts.js）"**，然后把下载的文件**替换 GitHub 仓库中的 `data/accounts.js`**（仓库中点开文件 → 铅笔编辑 → 粘贴内容 → Commit，或重新上传覆盖），修改才会对学生生效

## ⚠️ 必须了解的架构限制

GitHub Pages 只能托管静态网页，**没有服务器和数据库**，因此：

1. **学生的成绩和错题记录保存在学生自己设备的浏览器里**（localStorage）。同一学生换电脑、换浏览器或清除浏览器数据后记录不会自动同步。学生在"备份/恢复数据"中可导出文件、在新设备导入恢复。
2. **教师账号数据保存在网站仓库的 accounts.js 文件里**，网页上改完必须导出并更新到仓库才生效。
3. **判断题库仅 424 道**：每次考试 100 道，按"与近 5 次重复 ≤10%"计算，判断题大约能满足前 4 次考试的严格限制，之后新题不足会自动放宽重复率。如需严格执行，建议补充判断题或减少每次判断题数量。
4. **教师无法远程查看学生成绩**（没有服务器）。如需统计，可让学生截图"成绩记录"页，或收集学生导出的备份 JSON 文件。

如果以后需要"教师实时查看全班成绩、数据云端同步"，可以把网站迁移到支持后端的平台（如腾讯云开发、LeanCloud、Supabase 等），需要时可以再帮你改造。

## 文件结构

```
├── index.html          # 网站全部页面和逻辑（单文件应用）
└── data/
    ├── questions.js    # 题库（window.QUESTION_BANK）
    └── accounts.js     # 账号文件（window.ACCOUNTS，教师维护）
```
